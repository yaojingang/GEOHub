# Contributing

Thank you for your interest in GEOHub. External code merges are temporarily paused while the Contributor License Agreement receives legal review.

The project currently has no enabled CLA acceptance flow. The review draft in `CONTRIBUTOR-LICENSE-AGREEMENT.md` cannot be accepted. The project also does not currently use Developer Certificate of Origin (DCO) sign-offs as an alternative acceptance mechanism. A `Signed-off-by` line does not authorize a merge during this pause.

You may open an issue with a reproducible bug report, design observation, or documentation suggestion. Use the private channel in `SECURITY.md` for suspected vulnerabilities. Do not include confidential information, customer data, credentials, proprietary platform outputs, or content you lack permission to share.

Maintainers may discuss and triage proposals during the pause. A proposal, review, or discussion does not imply acceptance. When code contributions reopen, the maintainer will publish the approved CLA or DCO policy before accepting code. Changes will then be expected to target `main`, include focused tests, preserve protocol compatibility, and pass the complete `make verify` gate.

This project does not provide legal advice. Contributors should obtain their own advice when needed.
