# Trust Report

The crawler accepts one explicit public URL, revalidates DNS and redirects, binds HTTP requests to validated public addresses, restricts discovery to the approved host, honors robots for expansion, caps resources and time, rejects entity-bearing sitemap XML, and publishes through the atomic Artifact Bus. Optional browser rendering maps the approved host to a validated address and blocks off-host requests, media, fonts, and downloads.

The bundled ECharts runtime is Apache-2.0 licensed and executes only report data produced by the deterministic renderer. Live platform validation, Search Console or Bing Webmaster evidence, provider-backed evaluation, and human blind review are **missing evidence**.

Rollback boundary: remove generated run directories and revert the runtime, Registry entry, schemas, package data, and provider package together.
