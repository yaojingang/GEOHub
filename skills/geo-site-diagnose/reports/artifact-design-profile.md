# Artifact Design Profile

Artifact family: high-trust diagnostic dashboard and report. Visual direction: pure white canvas, ink-blue primary data, restrained green, amber, rust, and critical red status marks, with whitespace and type hierarchy separating primary sections. Neutral hairlines are reserved for sticky navigation, chart containers, dense tables, and explicit gap states. The ten-module sequence moves from summary through evidence and page validation to remediation. The full fixture carries 23 question-led chart views, while live evidence gaps remain visible. Tables, page checks, sticky navigation, and narrow-width layouts preserve review access.

Chart grammar uses solid fills, tabular values, wrapped labels, and one circular scatter symbol. The top radar prints scores on its axes without vertex markers. Page families use horizontal status bars, representative-page links use a numbered matrix, issue severity uses stacked bars, and the readiness funnel uses first-stage retention percentages with a visible loss remainder. Decorative textures, redundant marker shapes, dense sunburst labels, force-directed clusters, rotated labels, and ellipsized controlled labels are excluded.
