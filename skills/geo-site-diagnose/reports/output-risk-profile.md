# Output Risk Profile

- A polished report can overstate readiness; keep the limitation and confidence visible in the first viewport.
- Missing pages can make averages look stronger; show selected, observed, and source-gap counts together.
- Charts can hide exact values; include tables and page-level checks.
- Source text can contain executable markup; escape all content and serialize chart data safely.
- Current platform effects are unavailable; preserve them as **missing evidence**.
- A chart can imply a zero where evidence is absent; use a distinct gap state outside the score range.
- A dense chart inventory can weaken scanning; keep each module to one objective and no more than three charts.
- Sticky navigation and wide tables can overflow narrow screens; validate 1280 px, 375 px, and 320 px in an isolated browser.
- Decorative hatching, dots, triangles, diamonds, or background symbols can obscure the data; use solid fills and one circular scatter symbol.
- Rotated or ellipsized labels can hide the page type, dimension, or action; wrap controlled labels and preserve full text in tooltips and tables.
- A geometric funnel can exaggerate a small loss when minimum segment widths are used; calculate every stage as a percentage of the first valid stage and test the fixture ratio.
- Dense hierarchy and network charts can create unreadable sectors or crossing lines; use severity stacks and a numbered internal-link matrix for the bounded ten-page sample.
- Color-only status encoding can fail accessibility and print review; pair every status color with a number, status label, or table value.
