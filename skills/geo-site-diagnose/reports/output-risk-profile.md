# Output Risk Profile

- A polished report can overstate readiness; keep the limitation and confidence visible in the first viewport.
- Missing pages can make averages look stronger; show selected, observed, and source-gap counts together.
- Charts can hide exact values; include tables and page-level checks.
- Source text can contain executable markup; escape all content and serialize chart data safely.
- Current platform effects are unavailable; preserve them as **missing evidence**.
- A chart can imply a zero where evidence is absent; use a distinct gap state outside the score range.
- A dense chart inventory can weaken scanning; keep each module to one objective and no more than three charts.
- Sticky navigation and wide tables can overflow narrow screens; validate 1280 px, 375 px, and 320 px in an isolated browser.
