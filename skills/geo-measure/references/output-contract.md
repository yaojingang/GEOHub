# Measurement Output Contract

`visibility-report.json` contains:

- mention rate from explicit subject aliases;
- target-source inclusion rate;
- target citation share;
- position-weighted visibility using mention and reciprocal target-citation position;
- answer and observation coverage;
- missing observation rate;
- the same metrics per engine;
- query-level raw components and a semantic digest.

The semantic digest excludes generated time and output path. A report based entirely on recorded fixtures carries a gap stating that it does not prove live engine visibility. Cross-engine summaries keep each engine visible and cannot present one unqualified platform-performance score.
